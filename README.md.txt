Campus Shop Inventory Management System

Introduction

The Campus Shop Inventory Management System is a java-based project developed using Object-Oriented Programming (OOP) concepts to manage shop inventory.

Objectives

- To manage shop products.
- To track stock quantities.
- To update product information.
- To monitor stock availability.

Technologies Used

- Java
- Object-Oriented Programming (OOP)

Main Features

- Add products.
- View products.
- Update stock quantities.
- Manage inventory.

Conclusion

The system helps improve stock management, accuracy and efficiency in a campus shop.
